Pentatonica privacy policy

Last updated: September 22, 2026

Pentatonica is a puzzle game for Windows, Android and the browser. This policy explains what the game sends over the Internet and what happens to it.

What stays on your device

Your game in progress and your settings are stored only on your device and never sent anywhere.

The leaderboard

The leaderboard is the only part of the game that uses the Internet. Opening it downloads the current tables from the leaderboard server.

When a finished game makes the leaderboard, the game asks you for a name. Once you have one, each finished game is sent to the server: its score, the highest note reached, the number of moves, how long it lasted and when it ended. The number of moves and the duration are used only to check that the game is plausible and are not stored.

The server stores your name, your best score of all time, and your best score for each of the last 30 days. Older daily scores are deleted. Individual games are not kept.

When you choose a name, the game receives a player code, which lets you use the same name on another device. The server keeps only a one-way hash of this code, not the code itself. While you have a name, the game also asks the server for your best score when it starts, so that a best score set on another device appears on this one.

No email, account, contact details or device identifiers are collected. There are no ads and no analytics or tracking services.

Your network address

To prevent abuse, the server records your IP address when someone registers a new name or enters an unknown player code. These records are used only to limit repeated attempts and are deleted after an hour.

Hosting

The leaderboard server runs on Cloudflare Workers, and the browser version is hosted on GitHub Pages. Both process network requests, including your IP address, as described in their own privacy policies.

Your choices

You can turn score sending off in the game's settings at any time. Nothing is sent without a name. To have your name and scores removed from the leaderboard, open an issue at github.com/Mardivil/Pentatonica/issues.
